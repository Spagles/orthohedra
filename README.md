# Orthohedra

This project defines a web application for exploring *orthogonal polyhedra* -- roughly, shapes that can be made from assembling cubes.
These shapes can have remarkable properties, for example reproducing the
topology of the great rhombicosidodecahedron, an Archimedean solid with decagon, pentagon, and square faces.

Most of the requirements come from my friend David Richter, a professor of
Mathematics.
